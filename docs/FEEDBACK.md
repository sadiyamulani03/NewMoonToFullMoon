## Feedback Collection Method

Collected via a short online feedback form (Google Forms) shared after each tester tried the Preprod dApp at **https://midnighttrace.vercel.app**, plus optional follow-up in DMs/Telegram for specifics.

* **Collection period:** August 15, 2026 – September 13, 2026 (50 responses)
* **Form link:** https://docs.google.com/forms/d/e/1FAIpQLSdMZQVcwBSz4oQIHFUWWDdkxkBbyNo-wBMB7BiINVrQ70r9tw/viewform

* **Form fields (all optional, ~1 min):**
  1. Wallet address (Preprod) — for logging in `USERS.md`
  2. Overall experience — rating 1–5 (single choice)
  3. Ease of use — Very Easy / Easy / Normal / Confusing
  4. What did you like most? *(short text)*
  5. Hardest or most confusing part / issues *(short text)*
  6. Anything you'd change or add? *(short text)*

## What We Heard (Themes)

**Strongest positive themes (most mentioned):**
* Audit / audit verification — most recurring liked feature (Audit page, Audit window, verification easy to understand)
* Privacy / privacy-focused approach (privacy concept, privacy of forensic evidence)
* ZK proof concept / proof workflow / proof verification / proving without exposing evidence
* Dashboard
* Case creation / case management
* Simple / clean interface and interactive UI
* Ability to verify without exposing underlying evidence & immutable forensic trail (Zeel Chauhan, Fajrin, Samara, Rashi, Purva)

**Repeated improvement themes (2–4 mentions each — not presented as majority):**
* Transaction / proof progress indicators — Sanskruti Chavan, Purva Pawar, Sofiya Quraishi, Arya Bhagat, Jorge Soares, Amitabh Dey
* Clear transaction / proof status & "Proof confirmed" — Gayatri Panickar, Alicia Nadar, Amitabh Dey, Jorge Soares
* Faster transaction / proof processing — Tanishq Sonawane, Sanskruti Chavan, Purva/Auron (chain/proving time)
* Better wallet connection status & timeout handling — Anjali Ram Parde, Purva Pawar, Mustafa Berke Bakır
* Clearer first-time-user instructions — Purva Pawar
* Tooltips for technical terminology — Sakshi Manikari
* More explanation of ZK proofs / how verification works — Sheetal Goud, Debansh Tiwari
* Audit search / filter by case ID — Zeel Chauhan, Samara (2 requests)
* Landing page, privacy explanation on first screen, simplified documentation — Anam Pathan, Rashi Achaliya, Khushi Nagare (1 each)
* Better UI/UX generally — Anushka Kachare (1)

**Detailed UI/UX feedback — Mustafa Berke Bakır (2 responses, 2026-08-17) — counted as one perspective:**
* Complete localization/translation (UI mixed English/Turkish — browser auto-translation)
* Proper loading indicators and error toasts; timeout detection + RPC fallback
* Reduce harsh dense horizontal stripe background / improve readability and text contrast
* Add intuitive icons, status badges and network indicators
* Remove duplicate wallet connection buttons

**Bugs / friction:** Wallet connection timeout (Mustafa), few seconds to connect (Purva), terminology unclear (Sakshi — 1). No 2/5 or 1/5; no fabricated bugs.
