# NewMoonToFullMoon

This repository contains a Midnight Network level-1 project in the `level1/` subfolder.

## Project structure

- `level1/` - Midnight Compact contract application
  - `contracts/counter.compact` - the counter contract (public ledger + private witness + deliberate `disclose()`)
  - `contracts/hello-world.compact` - the starter hello-world contract
  - `contracts/managed/` - compiled contract artifacts and keys (generated by `compact compile`)
  - `tests/` - offline unit tests for the counter contract (`counter.test.ts`)
  - `src/` - deployment, CLI, wallet, and network scripts
  - `docker-compose.yml` - local devnet / proof-server services

## Getting started

From the repository root:

```bash
cd level1
npm install
npm run compile
npm test
```

Deploy your own counter contract:

```bash
cd level1
docker compose up -d --wait proof-server
npm run deploy -- --network preview --contract counter
npm run demo:counter   # calls increment + incrementAndReveal on-chain and reads the ledger back
```

## Contract behavior

The `counter.compact` contract maintains public ledger state (`total` counter and
`lastDisclosed`) while taking a private witness (`amount`) as a circuit input.
`increment(amount)` proves `total' = total + amount` without placing `amount`
on-chain; `incrementAndReveal(amount)` does the same but deliberately writes
`amount` into public `lastDisclosed` via `disclose()`. The starter
`hello-world.compact` contract works the same way: its `storeMessage` input is a
private witness that only becomes public when the contract calls
`disclose(customMessage)`. Full public/private breakdown lives in
`level1/README.md`.
