# NewMoonToFullMoon

This repository contains a Midnight Network level-1 project in the `level1/` subfolder.

## Project structure

- `level1/` - Midnight Compact contract application
  - `contracts/hello-world.compact` - compact contract source
  - `contracts/managed/` - compiled contract artifacts and keys
  - `src/` - deployment, CLI, network, and wallet scripts
  - `docker-compose.yml` - local devnet services

## Getting started

From the repository root:

```bash
cd level1
npm install
npm run compile
```

To deploy locally or to Preview/Preprod, use the scripts in `level1/package.json`.

## Contract behavior

This contract stores a public ledger value called `message`, which is visible on Midnight's shared state. The contract input to `storeMessage(customMessage)` is treated as a private witness. The witness is supplied to the ZK circuit at call time and only becomes public when the contract calls `disclose(customMessage)`.

## Initial product idea

A lightweight privacy-first message board where users can submit a private witness and choose whether its contents should be published. The on-chain contract records the final public message, while the witness ensures users can prove they control the input without exposing any extra private data. This could be extended into a “secret shout-out” service or a privacy-preserving anonymous feedback channel.

## Notes

- The actual Midnight application lives inside `level1/`.
- `contracts/managed/` is generated by `npm run compile` and should be present for deployment.
- `docker compose` is required for local devnet setup if deploying to a local network.
